# Esame
Formalmente esame Orale ma in realtà c'è una parte di domande scritte, esercizi che coprono tutto il corso, poi si inizia con l'orale.

Vengono dati 2 test (a crocette online) di *autovalutazione* durante il semestre, uno verso novembre, uno verso fine corso a dicembre (dopo la fine delle lezioni). A seconda dell'esito possono venire dati 1,2 o 3 punti in più all'esame (8,9,10 punti al test -> 1,2,3 punti all'esame).
